## **BƯỚC 2: Create New Project**

1. Click **"New Project"**
2. Click **"Deploy from GitHub repo"**

---

## **BƯỚC 3: Select Repository**

1. Choose GitHub (authorize if needed)
2. Select: **`daiduoc8288/daiminh-video-studio`**
3. Click **"Deploy"**

---

## **BƯỚC 4: Configure**

Railway sẽ auto-detect:
- Framework: Next.js ✅
- Build command: npm run build ✅
- Start command: npm start ✅

---

## **BƯỚC 5: Wait for Deploy**

- Railway sẽ build + deploy (5-10 mins)
- You'll get URL automatically!

---

## **BƯỚC 6: Get URL**

After deploy:
- Go to **"Deployments"** tab
- Copy the URL (like: `your-project-railway.up.railway.app`)

---

## **BƯỚC 7: Add Custom Domain**

1. Go to **"Settings"**
2. Click **"Domain"**
3. Add: **`video.daiminh365.vn`**
4. Follow DNS instructions
