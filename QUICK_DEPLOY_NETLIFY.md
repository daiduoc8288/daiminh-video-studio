# 🚀 DEPLOY VIA NETLIFY - SIÊU DỄ

**Netlify là easiest option - chỉ cần drag-drop!**

---

## ANH LÀM 3 BƯỚC (2 PHÚT):

### **BƯỚC 1: Vào Netlify**
👉 https://app.netlify.com

---

### **BƯỚC 2: Click "Add new site" → "Import an existing project"**

**Chọn GitHub:**
- Authenticate GitHub
- Select repo: `daiduoc8288/daiminh-video-studio`
- Select branch: `main`

---

### **BƯỚC 3: Configure & Deploy**

**Framework:** Next.js (auto-detect)

**Build Command:** `npm run build`

**Publish Directory:** `.next`

**Click "Deploy"** → Chờ 5 phút

---

## XONG!

Netlify sẽ tự:
- Build Next.js app
- Deploy lên CDN
- Cho URL (ví dụ: daiminh-video-studio.netlify.app)

---

**Sau đó anh báo em Netlify URL, em sẽ add custom domain!**
